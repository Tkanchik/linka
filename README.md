# linka

Установщик и менеджер обновлений для [Serpantinum](https://github.com/ilyamiro/serpantinum) под **Gentoo** и **Fedora Linux**.

Оригинальный Serpantinum собирается в первую очередь под Arch Linux. Если вы сидите на Gentoo или Fedora, ставить его руками — сомнительное удовольствие: половины пакетов нет в базовых репозиториях (нужны Guru/COPR), названия пакетов отличаются, для PipeWire и Qt6 требуются специфичные USE-флаги, а каждый апстрим-коммит рискует затереть ваши правки.

`linka` берёт эту рутину на себя: разруливает зависимости, аккуратно настраивает оверлеи и флаги, накатывает конфиги под выбранный композитор и помогает обновляться без боли.

---

## Быстрый старт

Установка одной строчкой (работает в bash, zsh, fish и других оболочках):

```bash
curl -fsSL https://raw.githubusercontent.com/Tkanchik/linka/main/install.sh | bash
```

Или через подстановку:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/Tkanchik/linka/main/install.sh)"
```

Скрипт скачает актуальную версию в `~/.local/share/linka`, положит команду в `~/.local/bin/linka` и откроет интерактивное меню, где можно выбрать нужный композитор и проверить пакеты перед установкой.

---

## Что умеет

- **Два дистрибутива:** одинаково аккуратно работает как на Gentoo (поддерживает и **systemd**, и **OpenRC**), так и на Fedora.
- **Поддержка композиторов:** Niri, Hyprland и Sway на выбор.
- **Бережное отношение к конфигам:** перед каждым обновлением создаётся бэкап в `~/.config/serpantinum-backups` (хранятся последние 5 копий). Ваши настройки не затираются вслепую.
- **Хуки для кастомных виджетов:** если вы дописываете свои компоненты, положите исполняемый скрипт в `~/.config/serpantinum/hooks/post_update.sh` — `linka` запустит его сразу после обновления.
- **Фоновые обновления:** можно включить тихую проверку раз в N минут (через `systemd --user` таймер или фоновый цикл). Можно настроить так, чтобы скрипт только присылал уведомление о новом коммите, либо обновлял шелл сам.
- **Чистый снос:** `linka remove` вернёт всё назад, удалит симлинки и отключит службы, не оставляя хвостов в системе.

## Основные команды

В повседневном использовании достаточно коротких команд в терминале:

```bash
linka                  # Интерактивное TUI-меню

linka update           # Проверить апстрим и накатить свежие коммиты
linka update --force   # Принудительно накатить поверх текущей версии

linka auto enable      # Включить фоновые обновления
linka auto status      # Посмотреть статус таймера и последние логи
linka auto disable     # Отключить автообновления

linka kill             # Остановить все процессы шелла
linka remove           # Полностью удалить Serpantinum и вернуть бэкапы
```

### Тонкая настройка автообновления

```bash
# Проверять каждые 30 минут, обновлять шелл автоматически, но не трогать системные пакеты
linka auto enable --interval 30 --shell apply --system off

# Только уведомлять о появлении свежих коммитов в репозитории
linka auto enable --shell notify
```

## Кастомные виджеты (`post_update.sh`)

Если вы пишете свои виджеты или модифицируете QML-код Serpantinum, создайте файл:

```bash
~/.config/serpantinum/hooks/post_update.sh
```

Сделайте его исполняемым (`chmod +x`). После каждого апдейта `linka` запустит этот скрипт — в него можно вписать копирование своих файлов поверх репозитория, правки стилей или перезапуск дополнительных демонов.
