# linka

Автономный установщик и менеджер обновлений для оболочки [Serpantinum](https://github.com/ilyamiro/serpantinum) на дистрибутивах **Gentoo** и **Fedora Linux**.

Оригинальный Serpantinum официально ориентирован на Arch Linux. Проект `linka` адаптирует процесс развёртывания под пакетные менеджеры `emerge` (Portage) и `dnf`, автоматизирует сборку необходимых компонентов и предоставляет удобный интерфейс управления обновлениями.

*Проект спроектирован и написан при участии искусственного интеллекта (AI-assisted).*

---

## Установка в одну команду

Запустите команду в терминале:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Tkanchik/linka/main/install.sh)
```

Или через конвейер:

```bash
curl -fsSL https://raw.githubusercontent.com/Tkanchik/linka/main/install.sh | bash
```

### Что делает скрипт установки:
1. Загружает репозиторий `linka` в `~/.local/share/linka` и создаёт симлинк в `~/.local/bin/linka`.
2. Определяет ваш дистрибутив (Gentoo или Fedora) и проверяет системные зависимости.
3. Открывает текстовое меню с выбором композитора (Niri, Sway или Hyprland) и параметров развёртывания.

## Архитектура проекта

В отличие от монолитных shell-скриптов, `linka` построена на модульном Python 3 без сторонних зависимостей (используется только стандартная библиотека, которая гарантированно присутствует в Gentoo и Fedora):

```text
linka/
├── install.sh             # Загрузчик для запуска через curl
├── linka                  # Основной исполняемый файл
└── linka_modules/         # Модули логики
    ├── distro.py          # Определение ОС и интеграция с emerge / dnf
    ├── deps.py            # Описание и проверка зависимостей
    ├── deploy.py          # Развёртывание ядра шелла, шрифтов и тем
    ├── compositors.py     # Конфигурации для Niri, Sway и Hyprland
    ├── updater.py         # Механизм обновлений и синхронизации с git
    ├── daemon.py          # Фоновая служба systemd --user для автообновлений
    ├── hooks.py           # Выполнение пользовательских хуков (post_update.sh)
    └── ui.py              # Консольный интерфейс и обработка аргументов командной строки
```

## Основные команды

После установки утилита доступна в терминале как обычная команда:

```bash
# Интерактивное меню управления
linka

# Чистая установка с выбором композитора
linka install --compositor niri

# Проверка и накат обновлений
linka update

# Принудительное обновление
linka update --force

# Включение фоновых автообновлений (systemd user timer)
linka auto enable

# Проверка статуса таймера автообновлений
linka auto status

# Остановка всех запущенных процессов шелла
linka kill

# Полное удаление
linka remove
```

## Сохранение пользовательских настроек

Если вы кастомизируете виджеты или файлы шелла, они не пропадут при обновлениях. В системе предусмотрен хук:

`~/.config/serpantinum/hooks/post_update.sh`

Скрипт автоматически вызывается после каждого обновления `linka update`, восстанавливая ваши персональные компоненты поверх свежего репозитория.
