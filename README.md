# linka

Скрипт для установки и обновления [Serpantinum](https://github.com/ilyamiro/serpantinum) на Gentoo и Fedora.

В апстриме Serpantinum рассчитан на Arch Linux. На Gentoo и Fedora его приходится собирать по частям: подключать оверлеи (Guru или COPR), искать пакеты с другими названиями, прописывать USE-флаги для PipeWire и Qt6 и руками следить за зависимостями композитора.

`linka` делает это сама: ставит пакеты через Portage или DNF, раскладывает конфиги под выбранный композитор и умеет проверять обновления в фоне.

## Установка

Команда установки скачивает последнюю версию ветки `main`:

```bash
curl -fsSL https://raw.githubusercontent.com/Tkanchik/linka/main/install.sh | bash
```

Скрипт клонирует репозиторий в `~/.local/share/linka`, делает симлинк в `~/.local/bin/linka` и запускает интерактивное меню настройки.

## Использование

Если запустить `linka` без параметров, откроется меню: там можно выбрать композитор, посмотреть статус пакетов, включить тему SDDM или запустить обновление.

Для терминала есть прямые команды:

```bash
linka                  # интерактивное меню
linka install          # установить зависимости и развернуть шелл
linka reinstall        # переустановить с нуля (с сохранением бэкапа конфигов)
linka update           # обновить шелл до свежего коммита
linka update --force   # принудительно перенакатить файлы текущей версии
linka kill             # остановить процессы шелла и демона
linka remove           # полностью удалить шелл (настройки предварительно бэкапятся)
```

`linka remove` оставляет пользовательские шрифты в `~/.local/share/fonts/IosevkaNerdFont`: в этом каталоге могут быть файлы, добавленные вручную.

Перед каждым обновлением и переустановкой `linka` сохраняет копию конфигов в `~/.config/serpantinum-backups/` (по умолчанию хранятся 5 последних копий). Если у вас настроен скрипт `~/.config/serpantinum/hooks/post_update.sh`, он автоматически вызывается после каждого наката файлов.

### Фоновые обновления

Проверку обновлений можно повесить на таймер `systemd --user` (или запустить встроенным демоном на OpenRC):

```bash
# Включить автообновление (по умолчанию каждые 15 минут)
linka auto enable

# Обновлять шелл, но системные пакеты не трогать
linka auto enable --interval 30 --shell apply --system off

# Только присылать уведомление о новом коммите без автонаката
linka auto enable --shell notify

# Настроить ветку, интервал проверки пакетов и уведомления
linka auto enable --branch main --every-days 2 --no-notify

# Проверить статус таймера/демона и последние строки лога
linka auto status

# Однократно запустить проверку обновлений вручную
linka auto run

# Запустить процесс демона в текущем терминале
linka auto daemon

# Полностью отключить автообновление
linka auto disable
```

#### Права sudo для фонового обновления системы

Если включено обновление системных пакетов (`--system apply` на Fedora или `--system notify|apply` на Gentoo), linka создаёт файл `/etc/sudoers.d/linka-auto` с правилом `NOPASSWD` строго на конкретные вызовы пакетного менеджера (`dnf` или `emerge`). Это нужно, чтобы фоновая служба не зависала в ожидании ввода пароля. Команда `linka auto disable` автоматически удаляет это правило.

## Поддерживаемые системы

- **Дистрибутивы:** Gentoo (systemd и OpenRC), Fedora
- **Композиторы:** Niri, Hyprland, Sway, MangoWM

Для MangoWM в меню выберите Mango или запустите `linka install mango`. Нужна версия MangoWM 0.18 или новее: конфигурация Serpantinum использует её параметры. На Fedora `linka` подключит Terra при необходимости. На Gentoo пакет берётся из GURU; если там ещё нет версии 0.18, установка конфигурации остановится с предупреждением. Когда MangoWM установлен, проверить конфиг можно командой `mango -c ~/.config/mango/config.conf -p`.

При первой установке и переустановке существующий `~/.config/mango` сохраняется в `~/.config/serpantinum-backups/`, а файлы Serpantinum копируются поверх него. При обычном обновлении непустой пользовательский конфиг сохраняется. Если каталог — симлинк, `linka` не меняет его целевой каталог и пропускает копирование конфига.

`linka` развивается при участии ИИ. Изменения проверяются перед выпуском.
